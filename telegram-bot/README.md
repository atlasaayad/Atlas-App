# بوت توقعات كرة القدم — Telegram

بوت Telegram يعمل تلقائياً على Railway، يتابع مباريات **الدوري الإنجليزي**،
**دوري أبطال أوروبا**، و**الدوري الإسباني**:

1. **قبل كل مباراة بساعتين تقريباً** — يبحث (عبر أداة البحث على الويب في
   Claude) عن التشكيلة المتوقعة والغيابات، ويولّد توقعاً بالنتيجة ونسبة ثقة،
   ويرسله كرسالة تحليل.
2. **بعد انتهاء كل مباراة** — يجلب النتيجة الحقيقية من football-data.org،
   يقارنها بالتوقع، ويرسل رسالة بالحكم: ✅ صحيح (نتيجة مطابقة تماماً) /
   ⚡ جزئي (الفائز صحيح لكن النتيجة مختلفة) / ❌ خطأ.
3. **كل إثنين الساعة 08:00** (حسب `TIMEZONE`) — يرسل ملخص إحصاءات دقة
   التوقعات لآخر 7 أيام.

## البنية

```
telegram-bot/
  bot/
    config.py       # قراءة متغيرات البيئة
    storage.py       # SQLite — سجل التوقعات والنتائج والإحصاءات
    football_api.py  # عميل football-data.org (المباريات القادمة/المنتهية)
    ai_analyst.py     # استدعاء Anthropic API (بحث ويب + توقع JSON منظم)
    predictor.py      # منطق المهام المجدولة (إعلان/حكم/إحصاء) + رسائل تيليجرام
    handlers.py        # أوامر /start /help /stats
    main.py             # نقطة التشغيل — يشغّل APScheduler + بوت تيليجرام معاً
  requirements.txt
  Procfile
  railway.json
  .env.example
```

لا علاقة لهذا المجلد بتطبيق ATLAS الرئيسي في جذر المستودع (Node/Vercel) —
مشروع Python مستقل يُنشر على Railway بشكل منفصل تماماً.

## ⚠️ ملاحظة أمان مهمة

شاركتَ توكن البوت ومعرّف المحادثة في المحادثة النصية. لم أضعهما في أي ملف
مرفوع لـ git — استخدم `.env.example` كقالب واضبط القيم الحقيقية فقط كمتغيرات
بيئة على Railway. **يُفضّل تدوير التوكن** عبر BotFather (`/revoke`) إن كنت
قلقاً من تسريبه، ثم استخدام التوكن الجديد.

## التشغيل محلياً (اختياري، للاختبار قبل النشر)

```bash
cd telegram-bot
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # ثم املأ القيم الأربع المطلوبة
python -m bot.main
```

أرسل `/start` للبوت على تيليجرام للتأكد من أنه يستجيب.

## النشر على Railway

1. **في مشروع Railway الحالي (`laudable-adventure`)** اضغط
   **New → GitHub Repo** واختر هذا المستودع (`atlasaayad/atlas-app`).
2. بما أن البوت في مجلد فرعي، افتح **Settings → Source** للخدمة الجديدة
   واضبط **Root Directory** إلى `telegram-bot`. Railway سيكتشف
   `requirements.txt` و`railway.json` تلقائياً (Nixpacks) ويستخدم أمر
   البدء `python -m bot.main`.
3. **Settings → Networking**: لا تُنشئ Public Domain — هذه خدمة خلفية
   (worker) بلا خادم HTTP، لا تحتاج منفذاً عاماً.
4. **Variables** — أضف المتغيرات التالية (القيم الحقيقية فقط هنا، وليس في
   الكود):
   | المتغير | القيمة |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | توكن البوت من BotFather |
   | `TELEGRAM_CHAT_ID` | `8281872164` |
   | `FOOTBALL_DATA_KEY` | مفتاحك من football-data.org |
   | `ANTHROPIC_API_KEY` | مفتاح Anthropic API الخاص بك |
   | `ANALYSIS_MODEL` | (اختياري) `claude-opus-5` افتراضياً |
   | `TIMEZONE` | (اختياري) `Africa/Cairo` افتراضياً |
   | `DATA_DIR` | `/data` (اربطه بـ Volume — الخطوة التالية) |
5. **إضافة تخزين دائم (Volume)**: من تبويب الخدمة اختر **Volume → New
   Volume**، اربطه بمسار `/data`. بدون هذا، سجلّ التوقعات (وبالتالي
   الإحصاءات الأسبوعية) يُفقد مع كل إعادة نشر، وقد تتكرر رسائل تحليل لمباراة
   أُعلنت للتو قبل إعادة النشر مباشرة.
6. اضغط **Deploy**. راقب الـ Logs — يجب أن ترى:
   `تم تشغيل الجدولة (توقيت Africa/Cairo) — البطولات: ...`
7. جرّب `/start` و`/stats` على البوت في تيليجرام للتأكد من أنه حي.

### الحصول على مفتاح football-data.org

سجّل مجاناً على https://www.football-data.org/client/register — الخطة
المجانية تكفي (حد 10 طلبات/دقيقة)؛ البوت يستهلك ~6 طلبات فقط كل 10 دقائق.

## كيف يعمل من الداخل

- **كل 10 دقائق**: مهمة تفحص مباريات كل بطولة القادمة خلال 3 أيام؛ أي
  مباراة يتبقى لها بين 100 و130 دقيقة (نافذة أوسع من فاصل الفحص لضمان عدم
  تفويت أي مباراة) ولم تُحلَّل بعد → يُستدعى Claude API مع أداة البحث على
  الويب لإيجاد التشكيلة/الغيابات وتوليد توقع JSON منظم، ثم تُرسل رسالة
  تيليجرام ويُحفظ التوقع في SQLite.
- **بنفس الفاصل**: مهمة تفحص مباريات كل بطولة المنتهية خلال آخر يوم؛ أي
  مباراة لها توقع محفوظ ولم تُحكَم بعد → تُقارَن النتيجة الحقيقية (من
  football-data.org مباشرة، بدون استدعاء AI إضافي) بالتوقع برمجياً:
  - **✅ صحيح** — النتيجة مطابقة تماماً (عدد الأهداف لكل فريق).
  - **⚡ جزئي** — نفس الفائز (أو التعادل) لكن بنتيجة مختلفة.
  - **❌ خطأ** — توقع فائز مختلف عن الحقيقة.
- **كل إثنين 08:00**: تُجمع كل التوقعات المحكوم عليها في آخر 7 أيام وتُرسل
  كملخص، مع معدل دقة تقريبي (صحيح = نقطة كاملة، جزئي = نصف نقطة).

## التخصيص

- **إضافة/إزالة بطولة**: عدّل `COMPETITIONS` في `bot/predictor.py` (رموز
  football-data.org — مثال `SA` لإيطاليا، `BL1` لألمانيا، `FL1` لفرنسا).
- **تغيير نافذة الإعلان قبل المباراة**: `pre_match_window_start_min` /
  `pre_match_window_end_min` في `bot/config.py`.
- **خفض تكلفة Anthropic**: غيّر `ANALYSIS_MODEL` إلى `claude-sonnet-5` (أرخص،
  أسرع) أو `claude-haiku-4-5` (الأرخص، دقة أقل للتحليل المركّب).
